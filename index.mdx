Base Fibonacci Division is a puzzle game where you factor numbers by sliding Fibonacci tiles across a grid. Each move applies the rules of Zeckendorf representation — breaking numbers down into sums of non-consecutive Fibonacci values. Play it locally on your desktop with Python and pygame, or launch it instantly in any modern browser via WebAssembly.

## Quick Start

<Steps>
  <Step title="Install">
    Clone the repository and install the required dependencies with `pip install pygame`.
  </Step>
  <Step title="Launch">
    Run `python main.py` from the project root to start the game on your desktop.
  </Step>
  <Step title="Play your first puzzle">
    Select a starting number, then slide Fibonacci tiles on the grid to factor it down to its Zeckendorf representation.
  </Step>
</Steps>

<Note>
  You can also play Base Fibonacci Division in any modern browser — no installation required. The browser version runs via WebAssembly using pygbag, so just open the link and start solving puzzles immediately.
</Note>
