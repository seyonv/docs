Base Fibonacci Division is controlled with mouse drag-and-click and a concise set of keyboard shortcuts. Every action you can perform with the keyboard is also available through the on-screen button bar at the bottom of the screen, so you can play comfortably with just a mouse if you prefer.

## Mouse Controls

| Action | Result |
|--------|--------|
| **Click** a tile | Selects it and highlights all legal move destinations in mint-green |
| **Click** a highlighted (mint) cell | Moves the selected tile to that cell |
| **Click + drag** a tile | Executes a split or merge move; release over any highlighted cell to confirm |
| **Click** an empty area | Deselects the current tile and clears all highlights |

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `U` | Undo the last move |
| `R` | Redo a previously undone move |
| `H` | Hint — highlights the next optimal move |
| `N` | New puzzle (same difficulty, fresh board) |
| `Esc` | Return to the main menu |

## Button Bar

The button bar runs along the bottom of the screen and mirrors every major action:

| Button | What it does |
|--------|--------------|
| **Undo** | Steps back one move in your history |
| **Redo** | Steps forward one move after an undo |
| **Reset** | Returns the board to its original starting state |
| **Hint** | Highlights the single best next move on the optimal solution path |
| **Solve** | Plays back the full optimal solution as a step-by-step animation |
| **New** | Generates a new puzzle at the current difficulty |
| **Sound** | Toggles sound effects on and off |
| **Log** | Slides the move log panel in or out from the right edge |
| **Menu** | Returns to the title / difficulty selection screen |

<Note>
  The **Solve** button plays back the complete optimal solution as an animation, executing each move one by one so you can follow the logic at your own pace. Undo, Redo, and other inputs are disabled while the auto-solve is running.
</Note>
